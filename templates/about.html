About this prototype

Log Analyzer imports authentication logs, applies three explainable rules and records evidence for each alert so an analyst can investigate. It is an educational SOC prototype: rule-based (no machine learning), run against synthetic data, and not a production SIEM. It has not had a production security audit.

Severity and confidence

Every alert starts at medium severity. It rises one level if the peak count reaches twice the threshold, and one more level if a successful login for the same IP or account follows the failures within 10 minutes. Confidence is low, medium (peak at least 1.5× threshold) or high (peak at least 2× threshold). Real policies need organizational context and tuning. IP addresses are never labelled malicious from this data alone.

What it never does

It does not block IPs, reset passwords, disable accounts or call external services.
